Quick Start

Use JSON requests and send authenticated calls with Authorization: Bearer <access_token>.

POST {{ base_url }}/api/auth/register/
Content-Type: application/json

{
  "username": "aisha",
  "email": "aisha@example.com",
  "password": "strong-password-123",
  "password_confirm": "strong-password-123",
  "fitness_level": "beginner"
}

Authentication

POST/api/auth/register/

Create an account and receive access and refresh tokens.

POST/api/auth/token/

Sign in with username and password.

POST/api/auth/token/refresh/

Exchange a refresh token for a new access token.

GET/api/auth/profile/

Read the authenticated user's profile.

PATCH/api/auth/profile/

Update profile fields such as name, date of birth, and fitness level.

Activities

GET/api/activities/

List the authenticated user's activity records.

POST/api/activities/

Create a workout record. Duration is minutes, distance is kilometers.

{
  "type": "running",
  "duration": 35,
  "calories": 310,
  "distance": 5.2,
  "date": "2026-05-02",
  "notes": "Easy pace"
}
GET/api/activities/{id}/

Retrieve one activity owned by the authenticated user.

PATCH/api/activities/{id}/

Partially update an activity.

DELETE/api/activities/{id}/

Delete an activity.
